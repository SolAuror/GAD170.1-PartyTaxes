# Diegetic UI: the accountant's things

Party Taxes is about money, paperwork and people you can't quite trust, so the UI is made of the objects an
exiled accountant would actually handle. Every screen element is something that exists in the fiction; the
numbers are what's written on it.

| Element | Object | Why |
|---|---|---|
| Town actions | **Your ledger book.** Each action is a line entry: hotkey in the red margin, the entry, its cost in the debit column. Hovering runs an ochre wash over the line; things done today are struck through. | You are the bookkeeper. Every choice is an expense you write down. |
| Navigation | **A wooden signpost**: Town Square, Notice Board, Tavern, Counting House. The board for where you are sticks out further. | Moving between places, not opening menus. |
| Job board | **Contracts tacked to a cork notice board**, each on its own sheet at a slight angle. | Jobs are posted by the town, not offered by a menu. |
| Tavern | **"Seeking work" notices** on the same board, with the terms of hire beneath. | Hiring is reading people's adverts and weighing them. |
| Counting House | **The ledger again**: payroll, audits, firing. | The books are where you find out who's stealing. |
| Battle | **Field expenses**: the same ledger, now listing what you can pay for mid-fight. | Even in battle you only ever spend money. |
| Decisions | **Documents that demand an answer**: an incident report stamped CAUGHT, a sealed petition for a raise, a letter about the night's events. | They interrupt you, as paperwork does. |
| Run setup | **The Queen's writ of sentencing**, a scroll with a royal seal. The charge, the severity of the audit and the case are filled in, and you sign it to begin. | It's literally how the story starts. |
| Run end | **A page of your ledger**, stamped with the verdict (PARDONED, HANGED, MUTINY...). | Your score is your books. |
| Characters | **Paper tags on twine** over each hero: level on a wax seal, name, HP in red ink, wage and mood. Enemies wear **wanted notices**. | Everyone in your party is a line item with a price. |
| Status | **A cloth banner**: blue in town, red in battle. | Readable at a glance, and in-world. |
| Party, gold, days | **Hang tags**: the company's name; a coin and your purse; **tally marks** for days served. | You're serving a sentence; you count the days like a prisoner. |
| Controls | **A note tacked to the corner.** | A reminder you'd write yourself. |
| Adventure log | **A scroll** with rolled wooden ends. | The chronicle of the expedition. |

## Editing it: Party Taxes > Bake UI into Scene
The UI is built by code, but you can bake it into real objects and edit them like any other UI:

1. Open `SampleScene`, then **Party Taxes > Bake UI into Scene** (commit first; it replaces anything baked before).
2. It saves the fonts as TMP font assets (`Resources/PartyTaxes/UI/Fonts/* SDF.asset`), saves prefabs to
   `Resources/PartyTaxes/UI/Baked` (PT Action Bar, PT Run Setup, PT Final Ledger, PT World Tag), places the three screens
   in the scene, and restyles the HUD prefab `UI/UI_PTonScreen.prefab` in place.
3. Edit away, then save the scene (and apply to the prefabs if you want the edits there too):
   - **PT Action Bar > Book**: each view is a `View.*` object (Main, Jobs, Tavern, Ledger, Combat, Confront, Raise, Event).
     Only Town Square is switched on; switch the others on to edit them.
   - **PT Run Setup** and **PT Final Ledger** are switched off in the scene (they open themselves); switch them on to edit.
   - **PT World Tag** is a prefab only: it's copied over each character at runtime. `screenHeight` sets its size on screen.
   - The HUD is edited in `UI_PTonScreen.prefab` (the texts sit on `<name> Plate` objects).
4. At runtime the game finds the baked copies and re-binds them **by name**, so keep the object names. Anything you change
   (position, size, font, colour, wording of fixed text) is kept; text that shows game state is rewritten as it changes.
   An element you delete is rebuilt from code at runtime. Without a bake, everything is built from code as before.

## Notes for changing it in code
- Everything is built at runtime (`PTActionBar`, `PTRunSetupPanel`, `PTFinalLedgerPanel`, `PTWorldTag`, `PTUIFactory.StyleHud`, `PTAdventureLog`) from helpers in `PTUIFactory`, through `PTUIBuilder` (which reuses baked elements by name). Colours, fonts, the type scale and sprites are in `PTUITheme`.
- Decorative art always sits on a `Background` child that layout ignores; a sliced Image on a layout container would report its whole border as a minimum size and inflate the layout.
- The art is generated by `Tools/UIArt/generate_ui_art.py`; tweak and re-run it. New images must be appended at the end of `ART` so the shared random stream leaves the existing images unchanged.
- In-world tag size and height: `screenHeight` and `lift` on `PTWorldTag` (or its baked prefab).
- HUD positions: `PTUIFactory.StyleHud` (or edit the baked HUD prefab).
